KEEP · comparison rules

Two checks before merging

Different objectives? Recompute each optimum and grade both methods on a common reference metric. Their own cost numbers are not interchangeable.

Different execution? Compare ideal and hardware results with the same reads, circuit and frozen angles. Record QPU shots and CPU runtime separately.

One QPU shot is not the same amount of time as one classical cost check.

Interface boundary: the current evidence slot returns A, D for a pairwise Ising cost. A full-read MEC objective or a whole recursive-QAOA solver is not automatically a drop-in replacement; agree on the interface before integrating it.
