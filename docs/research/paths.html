Possible QAOA research paths

Candidates from Blekos et al., §3.1, not a proven ranking on our data. Our cost has only pair terms, every bit string is allowed (no fixed number of 1s), and each answer has a twin with the same cost (01101 and 10010). Choose one path first, rather than implementing them all.

Recursive QAOA structural fit

Run QAOA and find a strongly agreeing or disagreeing pair. Lock its same/opposite relation, eliminate one binary variable and update the remaining couplings. Repeat, then brute-force the last few variables.

Why usPhasing is about relative bits. Pair averages ⟨ZiZj⟩ survive the twin symmetry; single-SNP averages cancel in the ideal, symmetric baseline circuit.
Plugs inA loop around QAOA, not just a circuit. The bench needs a whole-method interface before this can run alongside local search and annealing.
WatchA wrong lock can discard the optimum. Count every round's training and shots. At p = 1, pair averages have classical formulas: success alone is not quantum advantage.
Illustration: locks consistent with the toy optimum, not a performance benchmark.

Multi-angle QAOA worth a try
2 → 14 angles at p = 1 on the toy

Every gate gets its own angle, instead of all 9 ZZ gates sharing γ and all 5 X gates sharing β.

Why usMore freedom for differently weighted pairs, with the same ZZ/X gate pattern. May help at low depth, but more angles make training harder.
Plugs inCircuit + matching trainer: our COBYLA wrapper assumes 2p angles. Initialize rotations to match the trained baseline.
Warm-start QAOA worth a try

Use a classical relaxed solution (soft 0/1 guesses) to bias the initial state, and adapt the mixer to it. This is different from reusing trained angles.

Why usTest whether QAOA improves a classical head start. Keep soft guesses away from exact 0 or 1 so the matched mixer can still change bits.
Plugs inCircuit with fixed preparation/mixer settings and 2p trainable angles. Count classical preparation and compare against its answer alone.

Add a problem-derived block to help reach low-cost states in fewer layers. For our ZZ cost and X mixer, a first-order block uses weighted YZ + ZY pair rotations, not just single-qubit Y rotations.

WatchExtra two-qubit gates can erase the benefit of fewer layers. Compare depth and gates after routing, not p alone.

Lower priority: XY / Fermionic QAOAUseful for fixed-count constraints we do not have. An XY mixer preserves the count of 1s; starting in one count sector can exclude every optimum. A uniform start includes all sectors but cannot move probability between them.
Optional: adaptive-bias QAOAZero initial biases leave the ideal circuit symmetric, so single-qubit averages stay zero. Nonzero initial biases can break that symmetry: this variant is not ruled out, but needs a deliberate initialization study.
Later: Grover mixer, QAOA+, FALQONStill possible, not disqualified. Grover mixing is more general but not specifically tailored to our pair graph; QAOA+ adds gates, and FALQON's feedback loop can need many layers. Check resources before expanding the shortlist.

The review's comparison used unweighted MaxCut graphs with 4–18 nodes. Our graphs have ± weights, so its results do not establish a winner here. These are proposed paths, not implemented bench variants. Use the same instances and total shot budget (training included), and report classical effort, final optimum frequency and truth error.

Alex · Post-processing + hardware

the reality check

How much do routing and noise hurt, and how much can cheap classical clean-up of the samples win back?

SNPs placed on Manila's 5 qubits, which form a line (SNP 2–5 has no votes, so no gate). At most 4 of our 9 couplings can be neighbours. That is why 9 ZZ gates became 29 two-qubit gates.

Try
  • SNP order and initial layout chosen to match the chip, transpiler seeds, optimization level
  • fold: 01101 and 10010 are the same answer, so merge their counts
  • polish: flip single bits of each sample while the cost improves
  • real IBM run with job IDs; readout mitigation, dynamical decoupling
Measure
2-qubit gatesdepthoptimum freq. before/after
Gives →noisy counts + a clean_up(counts) function, to Tudor's bench
Needs ←circuits + frozen angles from Carla; random samples from Tudor as a control
Polishing can fix almost anything at N=5. Run the same clean-up on random samples too; if random + polish ≈ QAOA + polish, QAOA added nothing.

Alexandra · Objective variants + evidence

what "best" means

Is counting pairwise votes the right thing to minimise? Which reads and relationships should count more?

readSNP 1SNP 2vote
101opposite
210opposite
900same

SNP 1–2 votes: opposite 2, same 1, so read 9 is outvoted. Should it count less? And a read covering 3 SNPs casts 3 pair votes while a 2-SNP read casts only 1; a 10-SNP read would cast 45.

Try
  • per-read weights, so long reads don't dominate
  • MEC objective: the fewest letters to change so every read fits one copy
  • prune weak or tied edges: fewer ZZ gates, shallower circuits
  • deduplicate reads; down-weight conflicting reads

Tudor · Classical vs quantum + scaling + simulator

the test bench

As N grows, how does QAOA compare with classical methods at the same budget, and how far can we simulate?

Random guessing stops being enough at around N ≥ 14. That is where QAOA (or any method) has to concentrate probability to beat chance.

Try
  • generator: N SNPs, coverage, read length, error rate, missing rate, seed, with the hidden truth kept
  • classical: brute force, greedy + local search, simulated annealing
  • random sampling as the control
  • ideal simulation up to the memory limit, then cheaper tricks

4 · Shared rules

Rules every path follows

  • Same instances and seeds for every method being compared.
  • Same budget: shots or cost evaluations, written down.
  • Always include a random-sampling control row.
  • Recompute the exact optimum after changing the evidence.
  • Bitstrings read SNP 1 first; decode Qiskit keys once with decode_key.
  • Show failures too; a clear negative result is allowed.
5 · Only if we have room

Unassigned: information limits

If no read ever covers SNPs from two groups, the reads cannot tell how the groups line up. Every way of flipping a group is equally good, giving 2k−1 tied answers for k groups.

Cheap to add later: Tudor's generator can create gaps on purpose, and the bench simply counts tied optima.
